# social-notifications-service

Minimal Spring Boot microservice shell for future Chat, Notifications, Mailing, and Moderation features.

## Prerequisites

- Java 21
- Maven

## Build

```bash
mvn clean package
```

## Run

```bash
mvn spring-boot:run
```

or:

```bash
java -jar target/social-notifications-service-0.0.1-SNAPSHOT.jar
```
